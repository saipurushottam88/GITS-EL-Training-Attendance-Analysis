# GITS EL Training Attendance Analysis | Excel & Power BI

## Project Overview

This project focuses on analyzing student attendance in the Experiential Learning (EL) Training Program at Geetanjali Institute of Technical Studies (GITS).

The objective is to transform raw attendance records into meaningful insights using Microsoft Excel and Power BI. The project provides an interactive view of attendance patterns across different academic years, sections, genders, and technology tracks.

It also helps monitor student attendance against the mandatory 80% attendance requirement for internship/training certification.

## Problem Statement

Monitoring student attendance across multiple academic years, sections, and technology tracks can be challenging when dealing with large attendance records.

The goal of this project is to analyze attendance data, calculate attendance percentages, identify attendance statuses, and develop interactive dashboards to make attendance monitoring and comparison easier.

## Project Objectives

- Analyze student attendance across different academic years.
- Compare attendance across various sections.
- Examine attendance distribution by gender.
- Analyze participation across different technology tracks.
- Calculate individual attendance percentages.
- Identify students meeting the mandatory 80% attendance requirement.
- Present meaningful insights through interactive Power BI dashboards.

## Tools & Technologies

- **Microsoft Excel** – Data organization, processing, formulas, and conditional formatting.
- **Microsoft Power BI** – Data visualization and interactive dashboard development.

## Data Processing in Excel

The attendance dataset was organized and processed using Microsoft Excel.

Key operations performed:

1. Organized student information and attendance records.
2. Maintained date-wise attendance using binary values (1 = Present, 0 = Absent).
3. Applied Conditional Formatting to highlight attendance records.
4. Added calculated columns for attendance percentage.
5. Created attendance status based on the 80% eligibility requirement.
6. Prepared the processed dataset for visualization.

## Power BI Dashboards

The project contains two interactive dashboard pages.

### 1. Attendance Dashboard

This dashboard provides an overview of attendance records through:

- Section-wise Total Attendance
- Technology Track-wise Attendance
- Year-wise Attendance
- Gender-wise Attendance
- Active vs Not Active Status

Interactive slicers are provided for:
- Section
- Academic Year
- Gender
- Technology Track

### 2. Attendance Percentage Dashboard

This dashboard focuses on attendance percentage distribution and comparisons.

Visualizations include:

- Section-wise Attendance Distribution
- Gender-wise Attendance Distribution
- Technology Track-wise Distribution
- Year-wise Distribution
- Attendance Status Distribution

The dashboard also includes interactive filters to explore specific student groups and technology tracks.
